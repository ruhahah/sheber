# Деплой Sheber на Render

Сайту нужен сервер Node.js, поэтому на Render это **Web Service**, а не Static Site.
Настройки уже лежат в файле `render.yaml` в корне проекта, вручную вводить их не нужно.

## 1. Отправить код на GitHub

Render берёт код из репозитория `github.com/ruhahah/sheber`, ветка `master`.

```bash
git add -A
git commit -m "Add problem reports and Render settings"
git push origin master
```

Проверьте на странице репозитория, что файл `render.yaml` там появился.

## 2. Создать сервис

1. Откройте [render.com](https://render.com) и войдите через **GitHub**.
2. Нажмите **New** → **Blueprint**.
3. Выберите репозиторий `sheber`. Если его нет в списке, нажмите **Configure account** и
   дайте Render доступ к этому репозиторию.
4. Render покажет сервис `sheber` из файла `render.yaml`. Нажмите **Apply**.
5. Подождите 3–6 минут. В логе в конце должно быть `Your service is live`.

Адрес будет вида `https://sheber.onrender.com`. Если имя занято, Render добавит к нему
несколько букв; точный адрес написан вверху страницы сервиса.

### Если Blueprint не подходит

Создайте сервис вручную: **New** → **Web Service** → репозиторий `sheber`.

| Поле | Значение |
|---|---|
| Language | Node |
| Branch | master |
| Region | Frankfurt |
| Build Command | `npm ci --include=dev && npm run build` |
| Start Command | `npm run start` |
| Instance Type | Free |
| Environment → `NODE_VERSION` | `22.12.0` |

## 3. Проверить после деплоя

- Главная открывается, видны 13 уровней.
- Любая миссия открывается по прямой ссылке и после обновления страницы (F5), варианты
  ответа нажимаются.
- Переключаются язык и тема.
- Раздел Learn и страница «Результаты» открываются.
- Сайт открывается на телефоне.

## 4. Обновления

После каждого `git push origin master` Render сам пересобирает и публикует сайт.
Прогресс пользователей хранится у них в браузере и при обновлении не теряется.

## 5. Что нужно знать про бесплатный тариф

- **Сервис засыпает через 15 минут без посетителей.** Первый заход после этого длится
  30–60 секунд, дальше сайт работает быстро.
- **Перед показом жюри или тестом в классе** откройте сайт сами за 2–3 минуты до начала.
- Чтобы сайт не засыпал совсем, есть два пути: тариф Starter (платный) или бесплатный
  сервис вроде UptimeRobot, который открывает сайт каждые 10 минут. Месячного лимита
  бесплатного тарифа (750 часов) на один круглосуточный сервис хватает.

## 6. Если сборка упала

| Что в логе | Что сделать |
|---|---|
| `Cannot find module 'typescript'` или ошибка про `tailwindcss` | В Build Command должно быть `--include=dev` |
| Ошибка про версию Node | Переменная `NODE_VERSION` = `22.12.0` |
| `No open ports detected` или `Port scan timeout` | Start Command должен быть `npm run start` |
| Ошибка при загрузке шрифтов | Нажмите **Manual Deploy** → **Deploy latest commit** ещё раз |

Перед отправкой кода сборку можно проверить у себя:

```bash
npm run build
```
